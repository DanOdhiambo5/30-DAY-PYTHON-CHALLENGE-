# Day 9: Functions and Return Values 🐍

This lesson focuses on creating reusable Python functions, passing information into functions through parameters, and returning results for use elsewhere in a program.

## 📚 What I Practised

- Defining functions with `def`.
- Passing arguments into functions.
- Using parameters to make functions reusable.
- Returning formatted text and calculated values with `return`.
- Storing a returned value in a variable and using it later.

## 🧪 Exercises

### 1. Service Offer

File: `functions_practice.py`

A function named `service_offer()` accepts a skill, price, and delivery time. It returns a formatted service description. The function is called with different values to demonstrate reuse.

Run it:

```bash
python functions_practice.py
```

### 2. Calculate Area

File: `return_values.py`

A function named `calculate_area()` multiplies a length by a width and returns the result. The returned value is stored in the `area` variable and then displayed.

Run it:

```bash
python return_values.py
```

## 💡 Key Lesson

A function can use `return` to send a result back to the part of the program that called it. This makes it possible to reuse calculations and build programs in smaller, organised pieces.
