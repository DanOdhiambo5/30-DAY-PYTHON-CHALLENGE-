# Week 2 - Day 12: Milk Production and Expense Records

## Project Overview
A Python program designed to help dairy farmers record daily milk production and farm expenses.

The program allows users to enter multiple records, store information using lists and dictionaries, calculate totals, and generate farm reports.

## Features
- Record morning and evening milk production.
- Add multiple milk production records.
- Record farm expenses.
- Add multiple expense records.
- Calculate total milk production.
- Calculate total farm expenses.
- Display detailed milk production and expense reports.
- Generate a final farm summary.

## Python Concepts Practised
- Lists
- Dictionaries
- User input (`input()`)
- Type conversion (`float()`)
- While loops
- For loops
- Conditional statements (`if`)
- `break` statement
- `append()` method
- Accumulator variables (`+=`)
- f-strings and number formatting
