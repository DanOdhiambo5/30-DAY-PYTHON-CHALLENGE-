Python Loops Practice 🔁

This project contains practical exercises from Day 8 of my 30-Day Python Challenge. The goal was to understand and practise Python for loops, while loops, and loop control statements.

Features

Print numbers using for loops.

Generate multiplication tables.

Practise while loops.

Stop loops using break.

Skip iterations using continue.

Build a password guessing challenge.

Python Concepts Practised

for loops

while loops

range()

break and continue

Conditional statements (if)

User input using input()

Comparison operators (!=)

Variables and f-strings

Requirements

Python 3

No external libraries required.

How to Run

Open your terminal inside this folder and run:

python loops_Practice.py

Learning Outcome

I learned how loops control repetition in Python and how to use conditions to determine when a loop should continue or stop.
