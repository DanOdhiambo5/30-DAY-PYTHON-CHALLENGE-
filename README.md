Athlete Management Tracker

🚀 Featured Project: Athlete Management Tracker

The Day 6 project uses Python to manage a collection of athlete records.

It demonstrates how to:

Store athlete information using lists and dictionaries.

Display athlete records using loops.

Calculate the average athlete score.

Find the athlete with the highest score.

Add new athletes.

Search for an athlete by name.

Example

The tracker uses sample athlete records containing names, ages and scores. It calculates the average score and identifies the top-performing athlete.

⚙️ Getting Started

Clone the repository:

git clone https://github.com/DanOdhiambo5/30-DAY-PYTHON-CHALLENGE-.git

Enter the project folder:

cd 30-DAY-PYTHON-CHALLENGE-

Run the Day 6 athlete tracker:

python 6_athlete_tracker.py

No external Python packages are required for the current exercises.
