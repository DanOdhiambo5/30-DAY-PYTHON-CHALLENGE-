## 🚀 Projects and Exercises

### Day 6: Athlete Management Tracker

A Python project for managing athlete records. It includes practice with lists, dictionaries, functions, displaying records, calculating average scores, identifying the highest-scoring athlete, adding records, and searching by name.

### Day 7: Personal Expense Tracker

A command-line application for recording expenses and reviewing spending. It supports adding expenses, viewing records, calculating total spending, grouping totals by category, and validating user input.

The current version stores records in memory, so they reset when the program exits.

### Day 8: Loops

Practice using Python loops, including a multiplication table exercise.

### Day 9: Functions and Return Values

Exercises focused on defining reusable functions and returning values from functions.

### Day 10: Reading and Writing CSV Files

Practice reading student records from CSV files, working with the data, and writing updated records to CSV files.

### Day 11: Farm Records Tracker

A small Python project that works with farm records stored in a CSV file.

### Day 12: Milk and Expense Records

A command-line exercise for collecting milk and expense records, storing them in lists of dictionaries, calculating totals, and displaying a summary report.

## ⚙️ Getting Started

Clone the repository:

```bash
git clone https://github.com/DanOdhiambo5/30-DAY-PYTHON-CHALLENGE-.git
```

Enter the project folder:

```bash
cd 30-DAY-PYTHON-CHALLENGE-
```

Run a project or exercise from its folder. For example:

```bash
python day08_loops/day8_multiplication_table.py
python day11_farm_records_tracker/farm_records_tracker.py
python day12_milk_and_expense_records/milk_expense_records.py
```

The current exercises use Python's standard library and do not require external packages.
